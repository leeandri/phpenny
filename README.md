# phpenny 💰

**Une application PHP pour suivre les dépenses personnelles.**

phpenny est une application simple et légère conçue pour aider les utilisateurs à suivre leurs dépenses quotidiennes. Elle permet d’enregistrer, catégoriser et visualiser les dépenses de manière intuitive.

## 🛠️ Installation

1. Clonez le dépôt :
   ```bash
   git clone https://github.com/leeandri/phpenny.git
   ```
2. Placez les fichiers dans un serveur local (ex: XAMPP, WAMP).

3. Configurez votre base de données dans config.php.

4. Lancez l’application via votre navigateur :
   http://localhost/phpenny
